# Calculator

A simple calculator built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Features

* Addition, subtraction, multiplication, and division
* Decimal numbers
* Clear/reset functionality
* Delete functionality
* Chained calculations
* Displays the current calculation and result

## Built With

* HTML
* CSS
* JavaScript

## What I Learned

This project helped me practice:

* JavaScript functions
* DOM manipulation
* Event listeners
* Handling user input
* Working with numbers and operators
* Managing application state
* Using Git and GitHub
